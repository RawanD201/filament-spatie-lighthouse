# Security Policy

## Supported Versions

Only the latest release receives security fixes.

| Version | Supported |
| ------- | --------- |
| 1.x     | ✅        |
| < 1.0   | ❌        |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues, discussions, or pull requests.**

Report them privately through [GitHub Security Advisories](https://github.com/Rawand201/filament-spatie-lighthouse/security/advisories/new). If you cannot use GitHub, email **rawandrasool@proton.me** instead.

Please include:

- The type of issue (e.g. XSS, SQL injection, authorization bypass)
- The affected version(s) and the file(s) or component(s) involved
- Steps to reproduce, or a proof of concept
- The impact you believe the issue has

## What to Expect

- An acknowledgement within **3 business days**
- An initial assessment within **7 days**
- A fix released as soon as practical, depending on severity and complexity

Once a fix is released, a GitHub Security Advisory will be published and you will be credited unless you ask to stay anonymous.
